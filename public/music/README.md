# Hamnafas Unwind Music Library

The Unwind interface is now designed around musical listening rather than a large list of environmental sound effects.

For the hackathon build, use only music whose license permits redistribution/embedding in a web app. The following Pixabay tracks were researched as suitable royalty-free candidates:

1. Uplifting Calm — leberch (Pixabay Content License)
   https://pixabay.com/music/modern-classical-uplifting-calm-355592/
2. Calm Uplifting — leberch (Pixabay Content License)
   https://pixabay.com/music/modern-classical-calm-uplifting-313610/
3. Inspirational Calm — leberch (Pixabay Content License)
   https://pixabay.com/music/modern-classical-inspirational-calm-375197/
4. Deep Calm — The_Mountain (Pixabay Content License)
   https://pixabay.com/music/build-up-scenes-deep-calm-131380/

Download the MP3 files from the source pages and place them in this folder. Do not substitute Spotify/YouTube copyrighted recordings.

Suggested filenames:
- uplift.mp3
- sunrise.mp3
- flow.mp3
- deep-calm.mp3

The current Web Audio musical patterns remain as a lightweight fallback so the interface still works before the licensed MP3 assets are added.
